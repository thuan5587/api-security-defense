# API Security Defense

## Project overview
Research and implementation of RESTful API security defenses against BOLA and Broken Authentication.

## Team B11 - Assigned members
- Nguyen Thanh Thuan: BOLA, Ownership Check, Security Logging
- Phuoc Toan: JWT Validation, OTP Brute-force Protection

## Planned defenses
- Object-level authorization
- JWT signature and claims validation
- OTP attempt limiting and lockout
- Security event logging
- Before/after testing with Postman
